# Sales Prediction Using Python

## 📌 Project Description
This project predicts product sales based on advertising expenditure across TV, Radio, and Newspaper using Machine Learning.

## 🚀 Technologies Used
- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- HTML
- CSS

## 📂 Dataset
Advertising Dataset

## 🤖 Machine Learning Model
- Linear Regression
- Random Forest Regressor

## ✨ Features
- Predicts sales from advertising budgets
- Interactive web interface
- Accurate regression model

## ▶️ How to Run

```bash
pip install -r requirements.txt
python app.py
```

Open:

http://127.0.0.1:5000
