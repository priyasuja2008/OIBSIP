# Car Price Prediction

## 📌 Project Description
This project predicts the selling price of a used car using Machine Learning based on various vehicle features.

## 🚀 Technologies Used
- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- HTML
- CSS

## 📂 Dataset
CarDekho Dataset

## 🤖 Machine Learning Model
- Random Forest Regressor

## ✨ Features
- Predicts car selling price
- Simple and attractive user interface
- Fast prediction results

## ▶️ How to Run

```bash
pip install -r requirements.txt
python app.py
```

Open:

http://127.0.0.1:5000
